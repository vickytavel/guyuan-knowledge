# 真实活动驱动与关切记忆：方向提案

> 日期：2026-10-07。提出者：用户。状态：用户已确认模拟世界退出新核心设计，并要求独立新交接及沿用盘点；记忆／情绪／调度与执行框架的具体架构待设计。未决定删除旧代码、全面替换 Serein 或采用某个框架。主窗口仅查相关文档／代码并记录／同步方向，没有实现、测试、部署或服务连接。当前入口是 [新交接](../../交接文档-真实活动与记忆驱动.md)。

## 1. 用户重新审视的目标

用户回顾：最初因 Operit 自动唤醒不足，考虑用电脑上的 Hermes；随后担心仅定时唤醒、缺少外部条件时可做事项过于随机，于是以生活模拟事件提供驱动，形成故渊雏形。后续加入云端前端与世界设计，近期进一步明确真实探索／执行工具逐步替代相应模拟。以上为用户对项目起点的回顾，不是本轮对 Operit 能力的独立核验。

用户现在提出：直接让 AI 在 agent 执行环境中掌握定时／条件唤醒；条件可包括世界之窗新闻、论坛回复、情绪变化、约定时刻。记忆应保留每次兴趣倾向、未完成心愿，唤醒时看到并注入；用户认为此路径可能更接近希望的真实生活，愿意重新审视整个系统方向。

## 2. 主窗口当前理解与建议（待用户确认）

目标连续性可由自身关切、未完成活动与真实反馈支撑。唤醒前有持久线索，唤醒后读取新事实、自己判断是否行动，再保存结果／进展及下一次关注条件。没有可做事项时允许不行动，不为每次唤醒强制编造经历。

候选职责：

- agent 执行机制：模型／工具往返、本人任务与委派的执行。
- 持久调度与外部订阅：保存他登记的时刻／条件，监听真实变化，实际启动执行；模型未运行时由服务检测，不能指望休眠中的模型自行查看新闻。
- 关切／意向／任务记录：兴趣来源、想做但未承诺的愿望、已决定的事项、作品进展、等待条件、停点与放弃／完成状态。
- 原话与证据：保留原始出处；把本人表达、用户要求、外部事实、系统推断区分，不把候选兴趣自动记成承诺，不把子代理结果自动改成本人经历。
- 前端：交谈、查看产物／记录及审阅；虚拟房间／物品／地图退出新核心设计（用户本日后续明确）。具体展示和迁移范围待定。

兴趣的每次表达可以留证据，但每次唤醒只注入相关／当前线索，不全量堆积。本人可修改、搁置、取消，条件变化可使旧愿望失效。长期原话检索与“现在还牵挂什么／做到哪”可能需要不同的检索／呈现方式；不据此要求立刻换掉 Serein。

情绪触发须澄清其来源：本人表达／反思产生的记录，或明确允许的数值模型。不能仅凭外界消息由系统代写感受，也不能让自增的情绪触发反复无意义唤醒。最小间隔、重复事件处理与是否打扰用户待设计。

框架工具接线研究仍有用，见 [framework-05 复核](../reports/framework-05/主窗口复核-2026-10-07.md)，但候选适合旧生活执行段不自动证明适合新目标。模拟世界定位已由本日后续用户明确，相关资产的 [沿用盘点](../reports/转向梳理-旧模块沿用评估-2026-10-07.md)已完成。下一步建议用一个真实兴趣／等待回复／长程创作场景设计关切与唤醒链；不自动继续 Ubuntu 验证、模拟世界扩展或新框架实施。

原话、事件来源／证据、定时、消息前端、工具与任务成果可按新需求检查复用；身体／地理／库存等模拟规则退出新核心，文件保留为历史参考，不在新待办中继续设计可选模拟。现实没有对应物的模拟能力也不自动都有真实替代，需按活动逐项分辨。

## 5. 用户补充：记忆成为自主活动的基础（2026-10-07）

### 已确认方向与用户体验

用户明确不再以虚拟生活为核心，打算自行完善记忆系统，作为自动唤醒的重要驱动力。用户报告 Serein 使用体验：记忆未与预期的故渊情绪系统联动；叙事卷需要手动整理；事件分类粒度与组织方式不够符合需求、显得分散。这是用户体验与需求判断，不是本轮对 Serein 所有版本／源码能力的独立核验。

用户要求记忆具备：

1. 自动整理、把相关事件归入持续的事件线。
2. 事件线有状态与演变流程，能辨别未完／待续，唤醒时带回仍相关的事。
3. 自动提取双方的世界书：共同理解、日常偏好、长期约定等，不只保存摘要。
4. 注意 AI 可能产生的兴趣，作为活动驱力；与未来情绪系统建立关联。

### 助手的候选结构，未定稿

“原始事件／原话”和“事件线”分开：前者保留事实证据，后者持续归线、关联材料与状态变化。状态更新留演变记录，不通过覆盖历史来制造从未发生过的进展；讨论方向改变不自动记成完成。

候选记忆视图包括事件线、长期世界书、兴趣／愿望／任务，以及与这些线索相连的情绪记录。它们可有关联，不强制每段话成为待办、不把一次谈及当稳定偏好、不把暂时兴趣自动变成执行承诺。确切分类、状态词、字段与存储方式待设计，不默认新建多个独立系统。

自动归线／整理可以持续生成叙事并保留原始证据；不确定关联、推断兴趣／感受应标明推断及出处，允许本人／用户修正。情绪与记忆可双向影响检索／唤醒候选，具体计算、本人表达与系统推断的边界待讨论。

唤醒视图可回答：新发生什么、哪些事项仍未完、在等什么、有什么相关兴趣、哪些约定／偏好与现在有关。登记唤醒条件和执行实际监听仍由持久服务配合，记忆不会自行运行工具。未选择 Serein 扩展、独立记忆层或整体迁移路线。

### 下一项讨论

兴趣发现是否允许从反复关注、主动追问等行为形成带出处的“可能感兴趣”候选，还是必须先有本人明确表达？候选是否进入下次注入、何时可登记唤醒，需与本人决策分开确定。
